# Architecture

## Pipeline

```
SOURCE → SIGNAL → CLUSTER → SCORE → OPPORTUNITY → TURKEY ANGLE → SAVE/BUILD
collectSignals → clusterSignals → heuristicScores → aiProvider → prisma
```

Entry points: `prisma/seed.ts`, `npm run ingest` (`ingest/cli.ts`),
`npm run scheduler`, `POST /api/ingest`. All four call `runIngestion()`.

## Sources (`src/lib/sources`)

One interface, six providers:

```ts
interface TrendSource {
  name: SourceName;
  fetchItems(): Promise<RawSignalInput[]>;
  normalizeItem(item: RawSignalInput): RawSignalInput;
}
```

Live today: Hacker News (Algolia, keyless), Reddit (public JSON, keyless),
GitHub (keyless, token raises limit), Product Hunt (GraphQL, bearer token).
Google Trends and X emit synthetic rows in demo mode, nothing in realtime
mode (`DEMO_MODE=false`).

`collectSignals()` isolates failures per source, staggers starts, retries once.
HTTP errors include the first 200 chars of the response body.

## Indie-only policy (`sources/blocklist.ts`)

Big-tech launches are dropped before clustering: author/org match, flagship
product tokens as whole words (`\b`, so `metaphor` never matches `meta`),
repos over 10k stars, signals older than 60 days. GitHub queries additionally
carry `stars:<10000` plus `-user:` guards. Per-source filter counts surface in
`SourceStatus.filtered` and the admin page. Dashboard adds a profit filter
(`monetizationPotential >= 70/80`) alongside score/category/stage/build.

## Clustering (`ingest/cluster.ts`)

Demo rows group by explicit `rawData.trendKey`. Live rows group by
keyword/domain overlap (threshold 0.34). Group keys are slugified to
`[a-z0-9-]` — ids land in `/opportunities/[id]` URLs, so slashes, colons and
quotes in titles must never reach them.

## Scoring (`scoring/`, `config/scoring.ts`)

Seven sub-scores, weights in config (profit-first: monetization 20%,
buildability 15%, virality 5%). `overallScore()` is a pure weighted mean;
`npm run rescore` recomputes stored overalls after weight edits with zero LLM
calls. Heuristics use only brief facts; rationales cite source counts,
engagement and dates — never invented competitors or revenues.

## AI layer (`ai/`)

`AIProvider.analyzeCluster` / `generateBuildPlan`, one shared base for
OpenAI, OpenRouter and AgentRouter (Anthropic-compatible). Outputs are
Zod-validated. Any failure — HTTP error, timeout (60s), malformed JSON,
schema mismatch — falls back to the deterministic mock. Provider selection
never throws; unconfigured means mock with a warning.

`copyChecklist` (`clone` / `localize` / `skip`) is part of the validated
`BuildPlan` schema, generated by every provider including mock.

## Cost control (`ingest/run.ts`, `ingest/batch.ts`)

Each cluster hashes its inputs (signal ids + engagement + counts, no volatile
dates) into `fingerprint`. Unchanged clusters skip the LLM call; changed ones
run with concurrency 4. `lastIngestedAt` is touched on every run; rows unseen
for `PRUNE_AFTER_DAYS` flip to ARCHIVED unless saved by a user.

## Auth

Email + bcrypt, JWT in an HttpOnly cookie (`tr_session`). `requireUser()`
guards app pages; save/build-plan/preferences routes check `getUserId()`.
`User.plan` (`FREE|PRO|HUNTER`) exists for future billing.
